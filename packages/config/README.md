# Shared Config Package (`@perflens/config`)

This workspace package provides shared configurations for ESLint, TypeScript, and Prisma across the Perflens monorepo.

---

## 📦 Contents & Usage

- Shared ESLint configurations
- Shared TypeScript compiler options (`tsconfig.json`)
- Shared Prisma schema & configuration standards

Used by:
- `apps/web`
- `apps/api`
- `apps/worker`
- `packages/types`
- `packages/ui`
