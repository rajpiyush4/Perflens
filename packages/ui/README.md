# Shared UI Component Library (`@perflens/ui`)

Shared React UI components for the Perflens platform.

---

## 🎯 Features

- Reusable React components built for performance monitoring UIs.
- Styled using Tailwind CSS and Radix UI primitives.
- Compatible with React 18 & React 19.

---

## 📦 Usage

Import components in application workspaces (`apps/web`):

```tsx
import { ... } from '@perflens/ui';
```
